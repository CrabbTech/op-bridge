# Reference material

Local copies of Teenage Engineering's OP-1 field documentation, kept so the bridge and the
model can answer questions about the device without guessing.

- `op-1-field-user-guide-fw1.7.txt` and `.pdf`: the official user guide, firmware 1.7 edition, text extracted from the PDF
  (source: the "download as PDF" link on the web guide). Engines, envelope, FX, LFOs, drum mode, tape, mixer, sequencers,
  tempo and sync, settings, input and output, COM screen, MIDI settings, controller mode,
  disk mode and MTP.
- `midi-reference-fw1.7.0.txt`: the incoming MIDI message and CC tables from the web guide,
  firmware 1.7.0.
- `firmware-changelog.txt`: release notes 1.1.2 through 1.7.3 from the downloads page. Useful
  for knowing which feature arrived when (multichannel USB audio in 1.6.0, the CC map in 1.7.0).
- `../device.md`: our own brief, including what was verified on the real device.

Source pages: https://teenage.engineering/guides/op-1 and
https://teenage.engineering/downloads/op-1/field
